# 算法选择与大规模实验规范

## 先按结构缩小范围

| 结构 | 优先基线 | 候选扩展 |
| --- | --- | --- |
| 线性/混合整数 | LP/MILP 求解器 | 分解、启发式 warm start |
| 凸连续 | 凸优化/KKT | 多求解器交叉验证 |
| 光滑非凸 | 多起点局部优化 | DE、CMA-ES、PSO |
| 非光滑黑箱 | 随机/网格基线 | DE、PSO、贝叶斯优化 |
| 离散组合 | 枚举/DP/CP-SAT/MILP | GA、SA、禁忌、问题专用邻域 |
| 昂贵黑箱 | 少量设计点 | 贝叶斯优化、多保真/代理模型 |
| 多目标 | 单目标标量化基线 | NSGA-II/III、Pareto 档案 |

PSO 适合有界连续、梯度不可用且单次评估尚可承受的问题。标准 PSO 不天然处理离散变量、等式约束、严格可行性证明或全局最优证明；需要合适编码、修复/可行性优先规则和独立验证。

## 搜索证据

优先使用原始论文、期刊综述和当前库/求解器官方文档。为每个候选记录：问题结构、所需输入、复杂度/预算、超参数、约束处理、停止条件、已知失败模式和验证方法。检索当前题目时遵守比赛联网和公开讨论规则。

## 计算扩展

扩展顺序通常为：向量化目标 → 缓存重复评估 → 并行独立 seeds/候选 → 并行种群评估 → GPU 批评估。廉价目标上盲目多进程可能因进程开销变慢。

保留 20% 以上总时间用于复现、论文和最终验收。设置硬超时、最大评估次数和提前停止；任何资源扩展都不能改变目标函数或约束语义。

## 防选择偏差

先冻结比较指标和种子，再运行候选。不能在看到历史公开答案后调权重、范围或随机种子。报告全部计划运行、失败和超时；不要只保留赢家。算法选择由统计汇总、约束可行性和模型证据共同决定。
