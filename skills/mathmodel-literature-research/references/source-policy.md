## 1. 目标与基本原则

本阶段服务于模型选择、理论正确性、算法求解和验证设计，不以参考文献总数为目标。每条核心判断都应能沿以下链条回溯：

`query_id → source_id → claim_id → 原文定位 → 本题变量映射 → model_decision → verification_test`

必须区分“来源真实”“读到了来源内容”“来源支持当前说法”三个命题。任意一个成立都不能自动推出另外两个。

## 2. 来源层级

| 层级 | 定义 | 可承担的角色 |
| --- | --- | --- |
| S1 | 原始理论/算法论文、同行评审原始研究、官方标准、官方数据、官方软件文档 | 核心理论、算法、参数、标准和直接实证依据 |
| S2 | 高质量综述、教材、专著、权威手册 | 领域地图、术语、理论综述和方法比较；关键公式宜追溯到 S1 |
| S3 | 相似应用研究、学位论文、明确标注状态的预印本 | 类比、实现细节、候选路线和失败案例；不能独立支撑高风险核心结论 |
| S4 | 博客、百科、GitHub、搜索结果页、论坛、竞赛论文 | 仅用于发现关键词或线索，不得作为核心理论的唯一证据 |

竞赛获奖论文可用于发现表达方式、方法组合和评价思路，但其数值、引用和理论解释必须回到原始来源独立核验。

## 3. 三层核验

### 3.1 身份核验

`identity_status=verified` 至少要求题名、作者或责任机构、年份、载体可交叉核对，并存在 DOI、出版社页面、期刊页面、标准发布页、官方数据页或机构仓储等稳定标识。搜索结果 URL 不是稳定标识。

DOI 应优先通过 DOI 注册信息、出版社或期刊页面核对。不得根据相似题名猜 DOI、作者、卷期或页码。

`peer_review_status` 使用受控值：`peer_reviewed`、`preprint`、`official`、`book`、`thesis`、`not_applicable`。预印本必须标为 S3，不能伪装成 S1/S2。

### 3.2 内容访问

- `full_text`：访问并阅读到支撑所提取证据的正文位置；
- `abstract`：只可支持摘要明确陈述的高层结论，不能支撑正文公式、算法细节或限制条件；
- `metadata_only`：只证明来源存在，不可支持实质性 claim；
- `unavailable`：不可作为证据。

### 3.3 Claim 核验

每个采用的公式、定理、算法、评价指标、关键参数或外部事实都要有 `claim_id`。定位应具体到页码、章节、定理号、公式号、算法号、表号或可唯一识别的段落。只写“见该论文”不合格。

原文没有明确表达的推论应标为本项目的推导或假设，并设计验证，不得伪装成文献结论。

## 4. 证据角色覆盖

不设固定篇数，但至少处理以下角色：

- `analogous_problem`：相同领域任务或数学同构问题；
- `core_theory_model`：模型成立条件、理论或基础公式；
- `algorithm_solver`：求解算法、收敛、复杂度与实现条件；
- `validation_metric_baseline`：指标、基线、稳健性和对比方法；
- `data_parameter_standard`：数据口径、参数和行业标准；
- `limitation_failure`：失效条件、反例、偏差和误用风险。

某角色确实不适用时，可在报告中写 `<role>: N/A - <具体原因>`。不能以“时间不足”作为 N/A 原因。

## 5. 检索与筛选规范

检索必须覆盖直接问题、数学类比、核心理论、算法、验证/基线和限制六个通道，并记录精确检索式。优先检索原始论文和官方来源；综述用于建立地图，再沿参考文献追溯。

纳入标准至少考虑：问题结构匹配度、来源层级、可访问内容、时间有效性、是否存在可定位证据。排除理由应记录为不匹配、重复、仅摘要且不足以支持 claim、来源不可核验、质量不足或超出范围，不能只记录“没用”。

连续两轮增量检索没有发现会改变模型、假设、算法、验证、基线或限制判断的高价值来源，方可判定饱和。`search_log.csv` 必须用递增的 `search_round` 记录各轮检索，在 `new_high_value_source_ids` 记录新增高价值来源，在 `decision_impact` 中记录 `none/model/assumption/algorithm/validation/baseline/limitation`；PASS 要求最后两个不同轮次的所有记录均为 `none`。

## 6. 理论到模型的映射

映射至少回答：

1. 文献对象对应本题哪个实体、变量或过程？
2. 文献前提在本题是否成立，如何检查？
3. 单位、尺度、边界条件和目标函数是否一致？
4. 文献结论是直接采用、经推导改造，还是只作启发？
5. 哪个实验能证伪当前映射？

对局部优化、非凸模型、启发式算法和高维参数搜索，要单独检索全局性、初始化敏感性、收敛边界、替代求解器和基线，不得把一次运行结果当成模型优越性的证据。

## 7. 候选路线比较

至少比较两条路线，建议使用表格：

| 维度 | 路线 A | 路线 B | 证据/验证 |
| --- | --- | --- | --- |
| 问题结构匹配 | | | |
| 数据与可识别性 | | | |
| 关键假设 | | | |
| 求解与全局性风险 | | | |
| 验证与基线 | | | |
| 可解释性与写作成本 | | | |
| 失败模式 | | | |
| 来源强度 | | | |

选择理由必须能落到题面结构、数据证据和验证计划，不能只写“效果好”“经典”“容易实现”或“论文常用”。

## 8. 门禁判定

### PASS

- 来源身份、内容访问和 claim 支持分别核验；
- 采用的核心理论与算法至少有一条 S1/S2 且全文可定位证据；
- 六类角色覆盖完整或存在合理 N/A；
- 至少两条路线已比较；
- 两轮增量检索达到饱和；
- 不存在依赖 S4、搜索片段或模型记忆的核心决策。

### CONDITIONAL

只适用于真实的访问或主题稀缺问题；缺口不支配核心模型，且报告明确列出缺口、禁止断言、影响和补证动作。不得用 CONDITIONAL 隐藏尚未搜索或没有时间核验。

### FAIL

包括但不限于：来源身份未核验、核心公式无定位、只搜直接题名而未搜数学原型、没有算法或验证检索、未比较候选路线、把竞赛论文或博客当核心权威、声称阅读了实际未访问的正文。

## 9. 禁止事项

- 不编造题名、作者、年份、DOI、页码、引文或检索结果数量；
- 不把搜索引擎摘要、AI 摘要或二手转述写成原文证据；
- 不为满足数量保留与模型决策无关的文献；
- 不把相关性当因果性，不把应用相似当理论条件相同；
- 不在写作阶段临时加入未登记、未核验的新引用；
- 不用单次局部优化结果替代全局性分析、基线比较或多起点验证。
